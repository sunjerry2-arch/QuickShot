# 快截 QuickShot

Windows 截图工具。截图后直接复制到剪贴板，不保存文件。

> 本软件免费，仅在本仓库 [Releases](../../releases) 发布。如果你是付费购买的，请联系卖家退款。

## 和微信一起用（必看）

快截和微信默认都用 **Alt+A** 截图，但一个快捷键只能归一个软件：

- **微信先打开**：Alt+A 归微信，快截自动改用 Ctrl+Alt+A，并弹出提示。
- **快截先打开**（比如设了开机自启）：Alt+A 归快截，微信的截图快捷键会失效。

经常同时开着微信的话，右键托盘图标 → 快捷键，选 **Ctrl+Alt+A** 或 **不使用快捷键**。不使用快捷键时，右键托盘图标 → 截图。

## 下载

在 [Releases](../../releases) 下载 zip，解压后运行 `QuickShot.exe`，无需安装。支持 Windows 10 / 11。

首次运行如出现"Windows 已保护你的电脑"，点击"更多信息"→"仍要运行"。

## 使用方法

程序运行后常驻系统托盘。截图可以按快捷键，也可以右键托盘图标 → 截图。

| 操作 | 按键 |
|---|---|
| 开始截图 | Alt+A（可在托盘菜单更换） |
| 选中整个窗口 | 单击该窗口 |
| 完成并复制 | Enter / 双击选区 |
| 保存为图片 | Ctrl+S |
| 撤销 | Ctrl+Z |
| 退出截图 | Esc |
| 移动 / 调整选区 | 方向键 / Shift+方向键 |
| 画正方形、正圆 | 按住 Shift 绘制 |
| 直线、箭头保持水平/垂直/45° | 按住 Shift 绘制 |
| 文字换行 | Shift+Enter |
| 移动文字 | 拖动文字 |
| 放大 / 缩小文字 | 单击文字，拖四个角 |
| 修改文字 | 双击文字 |

选区下方的工具栏提供矩形、椭圆、直线、箭头、画笔、马赛克、文字标注。

快捷键和开机自启可在托盘菜单中设置。
