# 快截 QuickShot

Windows 截图工具。截图后直接复制到剪贴板，不保存文件。

> 本软件免费，仅在本仓库 [Releases](../../releases) 发布。如果你是付费购买的，请联系卖家退款。

## 下载

在 [Releases](../../releases) 下载 zip，解压后运行 `QuickShot.exe`，无需安装。支持 Windows 10 / 11。

首次运行如出现"Windows 已保护你的电脑"，点击"更多信息"→"仍要运行"。

## 使用方法

程序运行后常驻系统托盘。

| 操作 | 按键 |
|---|---|
| 开始截图 | Alt+A |
| 选中整个窗口 | 单击该窗口 |
| 完成并复制 | Enter / 双击选区 |
| 保存为图片 | Ctrl+S |
| 撤销 | Ctrl+Z |
| 退出截图 | Esc |
| 移动 / 调整选区 | 方向键 / Shift+方向键 |
| 画正方形、正圆 | 按住 Shift 绘制 |
| 文字换行 | Shift+Enter |

选区下方的工具栏提供矩形、椭圆、箭头、画笔、马赛克、文字标注。

快捷键和开机自启可在托盘菜单中设置。若 Alt+A 已被其他程序占用，将自动改用 Ctrl+Alt+A。
